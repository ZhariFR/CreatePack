## 🇬🇧 English

### 📦 What is it?

**CreatePack** is a small project made to make resource pack creation easier.

The idea is to import your textures, organize them and create your pack directly from the website, without having to edit the code to use it.

For now, the website is still a **demo**, so there may be bugs or things that still need to be improved.

### 🌐 Website

# 👉 https://zharifr.github.io/CreatePack/

The website works directly in your browser and **you normally don't need to modify the code to use it**.

### 💾 Saving your work

If you have already imported some textures and don't want to lose them, you can use the **Export** button.

It saves your textures and the data needed for your project.

You can then use the **Import** button to restore your save and continue working.

### 🛠️ Modifying the project

There are several `README` files inside the code explaining how to make certain modifications, especially how to **add or modify tiles**.

For normal use, however, **you don't need to edit the code**.

### 🤖 Claude

Around **20–30% of the project was made with the help of Claude**.

The project was then modified and adapted to fit what I wanted to make.

### ⚠️ Note

The website is still in development and may contain errors.

If something doesn't work correctly, it may simply be because the project is still a demo.
